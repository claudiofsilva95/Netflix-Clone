🎬 Netflix Clone – React.js

A Netflix-inspired web application built with React.js, consuming real movie and TV show data from The Movie Database (TMDB) API.
This project was created for study and portfolio purposes, focusing on componentization, API consumption, and UI/UX inspired by a real-world product.

🚀 Features

Dynamic list of movies and TV shows

Categories organized by genre

Movie details on hover (title, rating, genres, etc.)

Responsive layout inspired by Netflix

Real-time data consumption from TMDB API

🛠️ Technologies Used

React.js

JavaScript (ES6+)

CSS3

TMDB API
